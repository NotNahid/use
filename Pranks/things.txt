Mild (annoying but survivable)
Hide desktop icons — Right-click desktop → View → uncheck "Show desktop icons" (you already knew this one)
Rotate the screen — Press Ctrl + Alt + Down Arrow (or any arrow). Looks broken, fix is Ctrl+Alt+Up
Snap the window — hide the taskbar: right-click taskbar → Taskbar settings → toggle off "Lock the taskbar," then drag it to 0 height, then re-lock it
Medium (they'll suffer)
Swap mouse buttons — Settings → Mouse → switch to right-handed mode
Mouse speed to max or ultra slow — Settings → Mouse → pointer speed slider
Battery of shortcuts — rename every desktop shortcut to something different from what they open, or make a chrome shortcut open Edge 💀 (very personal attack)
Wallpaper — screenshot their desktop, set it as wallpaper, THEN hide icons. All clicks, nothing opens
